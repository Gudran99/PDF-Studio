# Contributing to PDF Studio

Contributions are welcome, including bug reports, documentation improvements, accessibility fixes and code changes.

## Local development

1. Fork and clone the repository.
2. Run `python -m http.server 8000` in the project root.
3. Open http://localhost:8000 in a modern browser.
4. Create a focused branch and make your changes.

## Before submitting a pull request

- Test opening, editing and exporting a sample PDF.
- Check page operations and the mobile layout when relevant.
- Use synthetic or public-domain test documents; never upload private PDFs.
- Preserve local document processing and disclose any new external network requests.
- Preserve third-party license notices.
- Describe the change, reproduction steps and tests performed.

Please keep pull requests focused. For significant changes, open an issue first to discuss the approach.

By submitting a contribution, you agree that your original contribution may be distributed under the project's MIT license. Third-party material must retain its own applicable license.
