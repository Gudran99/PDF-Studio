How it works ↓

Edit a PDF without uploading it anywhere

PDF Studio is a free PDF editor that runs entirely in your browser. Your document is opened and changed on your own device, so nothing is sent to a server. There is no sign-up and no watermark.

  • Edit existing text

    Click any line of text in the PDF to change, add or remove words. The editor matches the size, color and a similar font.

  • Add text and fillable fields

    Type anywhere on a page, or draw text fields that other people can fill in with common PDF readers.

  • Insert and crop images

    Drop in a logo or photo, drag it into place, resize it and crop it right on the page.

  • Whiteout, highlight and draw

    Cover parts of a page, highlight what matters, draw freehand or add rectangles.

  • Move anything

    Drag existing text or anything you added to a new spot. Guides help you line things up.

  • Organize and merge pages

    Rotate, reorder, duplicate or delete pages, add blank pages, and combine several PDFs into one.

How to edit a PDF

  1. Choose a PDF or drop it onto the page. It opens on your own device and is never uploaded.
  2. Pick a tool: Edit text to change existing text, Text to add new text, or Image, Whiteout, Highlight, Draw and Field.
  3. Use the page thumbnails to rotate, reorder, duplicate or delete pages, or add another PDF to merge it.
  4. Select Save PDF to download the edited file.

Questions and answers

Is PDF Studio free?

Yes. It is free to use, with no account, no page limit set by us and no watermark on your files.

Are my files uploaded to a server?

No. The PDF is read and edited by your browser on your own device. Closing the tab removes it from memory.

Can I edit the text that is already in a PDF?

Yes, for PDFs that contain real text. Editing works line by line and uses a font similar to the original. Scanned PDFs are pictures of pages, so their text can't be edited, but you can cover it and type over it.

Does it work on phones and tablets?

Yes. The editor works in modern mobile browsers. Tap an item to select it, then drag it or use the buttons that appear above it.

Can I make a PDF form that people can fill in?

Yes. Use the Field tool to draw text fields, name them and save. The fields can then be filled in with common PDF readers and browsers.

Are there any limits?

Password-protected PDFs can't be opened. Very large files depend on how much memory your device has, because everything happens in the browser.
